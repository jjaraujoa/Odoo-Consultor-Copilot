# Ejemplo de réplica de app — Fase 2

Este ejemplo crea en **staging** un modelo personalizado, campos de varios tipos,
dos vistas, una acción de ventana y sus menús. No incluye registros de negocio,
ACL, reglas de registro, automatizaciones ni reportes.

Copie toda la carpeta dentro de `replicas/<slug>/` del proyecto del cliente. Los
hashes del manifiesto corresponden exactamente a los tres archivos incluidos;
si modifica uno, vuelva a calcular su SHA-256 antes de analizar la réplica.

Los modelos nuevos quedan como estructura técnica para administradores hasta que
se defina su seguridad. La gestión automática de ACL y reglas pertenece a la
Fase 4.
