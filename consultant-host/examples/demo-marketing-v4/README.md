# Ejemplo Marketing comercial schema 4

`mcp-request.json` muestra la entrada comercial cerrada. El archivo de imagen
debe existir en `demostraciones/<slug>/assets` y su SHA-256 se suministra en la
petición. El motor genera un escenario con `delivery_mode: database_records`,
nombres visibles naturales y propiedad técnica invisible.

El ejemplo solo prepara la vista previa. La base no cambia hasta que el
consultor escriba exactamente `CREAR-DEMO <id>`.
