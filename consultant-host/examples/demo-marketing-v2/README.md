# Ejemplo Marketing comercial v2

> Ejemplo histórico para comprobar lectura de escenarios heredados. No usar como
> plantilla de una demo nueva; `image_url` y los marcadores visibles quedaron
> reemplazados por el contrato schema 4.

`mcp-request.json` es una entrada completa y válida para
`demo_preparar_escenario`. El motor reemplaza los textos por componentes con un
marcador único, genera los bloques visuales y calcula todos los hashes.

`scenario-v2.example.json` muestra la forma del escenario resultante. Es
deliberadamente no ejecutable: hashes, fechas y artefactos generados aparecen
como marcadores. Nunca se debe editar ni firmar manualmente un escenario; hay
que crearlo con la herramienta MCP.

El ejemplo deja Website no publicado, Survey y Marketing Automation inactivos y
los mailings en borrador. No envía formularios, correos ni mensajes.
